## 🔤 Сувора типографіка та інтелектуальне скорочення

1. **Правило дефісу (Hyphen-only):**
   - У всіх текстах, промптах Gemini та публікаціях **СТРОГО ЗАБОРОНЕНО** використання довгих тире (`—`) та середніх тире (`–`).
   - Використовується **ВИКЛЮЧНО звичайний дефіс (`-`)**. Функція `sanitize_typography` примусово нормалізує будь-який вхідний та вихідний текст.
2. **Розумне скорочення довгих текстів (Smart Condensation):**
   - Якщо текст перевищує ліміти мікроблогів, Gemini AI автоматично або по кнопці `✂️ Скоротити тексти` стискає опис під точні ліміти (X: <= 240, Threads: <= 400, Bluesky: <= 250, Shorts назва: <= 100).
   - Зберігається головний сенс, емоційний гачок (hook) та заклик до дії (CTA) без обрізання слів навпіл.
3. **Оптимізація під пошукові запити (Social SEO 2026):**
   - **Search Bar Match**: Входження точного пошукового запиту в перші 1-2 рядки опису (закріплення у пошуковому блоці 'Search: [запит]' у TikTok та Instagram Explore).
   - **LSI-семантика**: Органічне вплетення 3-5 супутніх ключових слів та синонімів у тіло посту без переспаму (Keyword Stuffing).
   - **Нішеві пошукові кластери**: Заміна безглуздих хештегів (#fyp #rec) на реальні тематичні пошукові категорії (#smmпоради #автоматизація).
   - **4 готові SEO-пресети в боті (`[⚙️ Промпт Gemini]` -> вибір пресету)**:
     - 🔍 *Пошук + Вірусність* (базовий рекомендований баланс)
     - 📚 *Гайди / Інструкції (How-To SEO)*
     - 🏆 *ТОП-добірки та Рейтинги (Top List SEO)*
     - 💼 *Комерційний / Продажі (B2B & E-commerce)*

## 🛡 Захист від тіньового бану та безпековий аудит

### 1. Матриця залежності від IP
- 🔴 **IP-залежні мережі (Обов'язковий US / New York IP):**
  - **TikTok:** Алгоритм прив'язує країну пушу до IP, ASN та SIM. Невідповідний IP залишає відео без охоплення в США, а брудні датацентр-проксі призводять до вічного "0 views jail" (тіньовий бан).
  - **Instagram Reels:** Meta фіксує зміну геолокації та кидає акаунт на SMS-чекпоінти чи знижує рейтинг Reels.
  - **Facebook Reels:** Спільний з Instagram штучний інтелект контролю фроду.
  - **Snapchat Spotlight:** Гео-огороджений доступ для США.
  - **Threads:** Успадковує trust-score Instagram.
- 🟢 **Пряме підключення (Direct API, без проксі):**
  - **YouTube Shorts:** Працює через офіційний Google OAuth2. Зміна IP через проксі викликає скидання токенів (Security Alert).
  - **Bluesky:** Відкритий AT Protocol.
  - **Telegram Канал:** Прямий Bot API.

### 2. 100% Безкоштовний New York IP
- **Webshare.io Free Tier:** 10 безкоштовних постійних приватних SOCKS5 проксі в США (без карти).
- **Fly.io Free Tier у `ewr` (New York Metro):** Власний приватний SOCKS5 сервер на базі `microsocks` на безкоштовному тарифі Fly.io. Детальна інструкція в [`scripts/setup_free_ny_proxy.md`](file:///Users/bohdan/Downloads/Telegram%20Desktop/Channel%20Automations/scripts/setup_free_ny_proxy.md).
- **Захист від DNS-витоку (DNS Leak):** Автоматичне використання схеми `socks5h://` для віддаленого резолвінгу DNS на вузлі в Нью-Йорку.
- **Pre-flight Check:** Якщо увімкнено `STRICT_PROXY_CHECK=true`, бот блокує публікацію в чутливі мережі у разі відсутності перевіреного US IP.

### 3. Цифрове маскування контенту (Anti-Detection)
- **FFmpeg & Pillow Pipeline:** Повне видалення EXIF, XMP, GPS та маркерів пристрою.
- **Унікальний цифровий хеш (Unique SHA-256):** Мікро-зсув гамми відео (1.0002), гучності звуку (1.001) та 1-піксельна модифікація фото гарантують унікальний відбиток файлу на кожній платформі.
- **Humanized Jitter:** Рандомізована затримка (2-5 секунд) між публікаціями на різні платформи для імітації дій живої людини.

### 4. Локальна безпека (Anti-Credential Leak)
- Токени, паролі та сесії зберігаються **ВИКЛЮЧНО локально** з правами `chmod 600` / `700`.
- Повне маскування токенів, паролів проксі та sessionid у логах та звітах про помилки (`SecurityGuard.sanitize_error`).

## 🔥 Автоматизація #2: TikTok Вогники (Streaks) & Сердечка для Дівчини

Повна автономна система щоденного підтримання вогників у TikTok із розділенням на романтичний режим для коханої та дружні нагадування для решти контактів:

1. **Романтичний режим для Дівчини (Heart Stream):**
   - Бот визначає вказаний акаунт дівчини (`is_girlfriend = 1`).
   - Замість звичайних вогників генерує теплі, щирі, закохані ранкові повідомлення, наповнені сердечками (`❤️`, `🥰`, `💖`, `💕`, `💓`, `💞`, `🌸`, `✨`).
   - Завдяки інтеграції з Gemini AI тексти щодня унікальні та не повторюються.
   - За відсутності зв'язку чи API-ключа спрацьовує перевірена офлайн-бібліотека романтичних шаблонів.
   - Строге дотримання правила типографіки: виключно дефіс (`-`), нуль довгих тире.

2. **Дружні вогники для друзів (Streak Fire):**
   - Усім іншим контактам надсилаються різноманітні дружні повідомлення зі знаком вогника (`🔥`) для збереження серії днів.

3. **Керування прямо з Telegram-бота (`/streaks` або кнопка в головному меню):**
   - `👸 Вказати акаунт дівчини` ➔ швидке введення або зміна нікнейму коханої в один клік.
   - `💌 Тест сердечок (Дівчина)` ➔ миттєва генерація та прев'ю сьогоднішнього романтичного повідомлення прямо в чат Telegram.
   - `👥 Список контактів` ➔ перегляд усіх контактів, статусів дівчина/друг, лічильника днів серії та кнопки швидкого видалення (`❌`).
   - `➕ Додати контакт` ➔ реєстрація нового друга для щоденного обміну вогниками.
   - `🚀 Відправити всім зараз` ➔ позаплановий запуск розсилки з докладним звітом.
   - `⏰ Розклад (10:00)` ➔ зміна щоденного часу автоматичного спрацьовування.
   - `📜 Останні логи` ➔ історія успішних відправок, помилок та текстів.

4. **Анти-бан та безпека:**
   - **Demo / Dry-Run готовність:** До внесення реального `TIKTOK_SESSION_ID` усе можна тестувати в боті без ризику.
   - **US / New York IP:** Усі запити до TikTok Web Messaging проходять виключно через перевірений проксі.
   - **Humanized Jitter:** Рандомізована пауза 3.0-6.5 секунд між повідомленнями контактів.

   - Жодних кліше штучного інтелекту ("чим можу допомогти?", "я ШІ").
2. **Надшвидкий рушій Groq API (GPT OSS 120B):**
   - Працює через `groq` SDK з моделлю `openai/gpt-oss-120b` (або `llama-3.3-70b-versatile`) із генерацією до 500 токенів/сек.

   - Запам'ятовує факти про людей (як звати, у що грають, що розповідали).
